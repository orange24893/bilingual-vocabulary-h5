# IELTS / TOPIK 双语词汇学习小程序设计

## 1. 产品目标

制作一款面向 IELTS 英语与 TOPIK 韩语备考的微信小程序，帮助用户每天学习新词、录入阅读或听力中遇到的生词，并按照艾宾浩斯记忆曲线持续复习。

首版的核心体验是：分层释义、图文例句、完整标准朗读，以及英语和韩语完全独立的学习队列。

## 2. 已确认的关键决策

- 平台：微信小程序，使用 Taro 开发。
- 架构：Taro 小程序 + 云端内容生成 + 本地学习记录。
- 新词目标：英语、韩语分别设置，默认每种语言每天 30 个新词，可调整。
- 生词录入：自动生成，保存前可修改。
- 英语释义顺序：英文释义 → 中文释义。
- 韩语释义顺序：英文释义 → 韩文释义 → 中文释义。
- 朗读方式：自动播放标准发音，完整播放结束后才能继续；首版不做用户跟读评分。
- 语言隔离：英语和韩语拥有独立的新词进度、复习队列、学习记录与生词本视图，绝不在同一学习 session 中混排。
- 首版不依赖登录，本地学习记录不自动跨设备同步。

## 3. 总体架构

### 3.1 小程序端

负责语言选择、每日任务、学习流程、生词管理、音频播放门禁、复习调度、本地持久化和异常提示。

### 3.2 云端服务

负责：

- 根据单词和语言生成分层释义、短语、例句与翻译。
- 生成配图。
- 生成单词、短语、例句的标准语音。
- 保存必要的生成结果，避免重复生成。

所有第三方 API 密钥只保存在云端，不进入小程序源码或本地存储。云端响应必须通过字段校验后才可保存为可学习词条。

### 3.3 本地数据

内置 IELTS / TOPIK 基础词库随小程序发布。用户生词、生成后的内容、学习状态、每日记录、设置和可用媒体缓存保存在本机。

## 4. 语言隔离

### 4.1 学习入口

“学习”栏首先展示两个独立入口：

- IELTS 英语学习：英语新词进度、英语待复习数量、开始英语学习。
- TOPIK 韩语学习：韩语新词进度、韩语待复习数量、开始韩语学习。

进入某一语言后，整个学习 session 只包含该语言。学习页顶部持续显示当前语言。用户可以退出后切换语言，但不能在学习过程中混合两种语言。

### 4.2 独立统计

以下数据按语言分别计算：

- 每日新词目标与完成数。
- 到期与逾期复习数量。
- 新词和复习完成数。
- 学习中与已掌握数量。
- 连续学习天数。

当天完成至少一个新词或复习任务，即计为该语言当天有学习记录。连续学习天数不因另一种语言的学习而增加。

## 5. 每日任务与复习调度

### 5.1 队列顺序

每天按当前语言生成任务：

1. 已逾期复习词，按原到期日从早到晚排列。
2. 当天到期复习词。
3. 未达到每日目标的新词。

复习不会被新词挤掉。例如当天有 12 个复习词，新词目标为 30，则完整任务为 12 个复习词加 30 个新词。新词从内置词库和用户生词中提取，用户确认保存的生词与内置词使用相同调度规则。

每日目标修改只影响之后的新词分配，不清空已完成记录。

### 5.2 艾宾浩斯时间表

首次学习当天为 D0，之后复习时间为：

| 完成阶段 | 下一阶段的目标日期 | 距下一阶段的间隔 |
| --- | --- | --- |
| 初始学习 D0 | D1 | 1 天 |
| 第 1 次复习 D1 | D2 | 1 天 |
| 第 2 次复习 D2 | D4 | 2 天 |
| 第 3 次复习 D4 | D7 | 3 天 |
| 第 4 次复习 D7 | D15 | 8 天 |
| 第 5 次复习 D15 | D30 | 15 天 |
| 第 6 次复习 D30 | D60 | 30 天 |
| 第 7 次复习 D60 | 已掌握 | 不再自动复习 |

目标日期表示按时学习时相对首次学习日的名义日期。每次选择“认识”后，从本次完成日加上对应间隔计算下一到期日，因此逾期完成不会导致多个复习阶段在同一天集中出现。所有日期按用户设备所在时区的自然日计算，不要求在特定时刻完成。

### 5.3 掌握反馈

每次学习或复习完整结束后，用户选择：

- 认识：完成当前阶段，按时间表安排下一阶段。
- 模糊：不完成当前阶段，第二天重复当前阶段。
- 不认识：回到初始阶段，第二天从 D1 复习节奏重新开始。

逾期任务不会消失。完成 D60 复习并选择“认识”后进入已掌握列表，不再自动出现，但可以手动重新加入复习。

### 5.4 跨天与恢复

每完成一个学习步骤立即保存。中途退出后恢复到当前单词和当前阶段，当前音频必须重新完整播放。跨天后保留历史完成记录，并按新日期重新生成队列，逾期复习优先。

## 6. 单词学习流程

### 6.1 英语单词

1. 显示单词、音标、配图和英文释义，播放单词标准发音。
2. 单词音频结束后解锁下一步，查看中文释义。
3. 显示常用短语及中文翻译，播放短语发音。
4. 短语音频结束后，显示例句及中文翻译，播放完整例句。
5. 例句音频结束后，选择认识、模糊或不认识，保存调度结果并进入下一词。

示例 `negligible`：

- 英文释义：`so small or unimportant that it is almost nothing`
- 中文释义：`微不足道的；可忽略不计的`
- 短语：`a negligible amount`
- 例句：`The damage was negligible.`

### 6.2 韩语单词

1. 显示单词、罗马音、配图和英文释义，播放韩语标准发音。
2. 单词音频结束后查看韩文释义。
3. 再查看中文释义。
4. 显示常用短语及中文翻译，播放短语发音。
5. 显示例句及中文翻译，播放完整例句。
6. 选择掌握反馈，保存调度结果并进入下一词。

### 6.3 音频门禁

- 单词、短语和例句按顺序播放，不提供快进、拖动进度或跳过。
- 下一步只能由音频正常播放结束事件解锁，不能用固定计时器代替。
- 允许重播；重播时当前步骤重新变为未完成，播放再次结束后才能继续。
- 自动播放被平台拦截时，显示明确的播放按钮，用户点击后开始；仍不允许跳过。
- 切入后台、音频中断、加载失败或播放失败均不视为完成。
- 恢复学习后从当前音频开头重新播放。
- 首版使用一致的标准英语与韩语语音，不包含发音评分。

## 7. 页面结构

### 7.1 学习首页

- 展示 IELTS 英语和 TOPIK 韩语两个独立入口。
- 每个入口展示新词进度、待复习数量和连续学习天数。
- 有复习任务时优先引导复习。
- 支持继续未完成的 session，不重复计算已完成单词。

### 7.2 单词学习页

- 顶部显示当前语言、新词或复习类型、复习轮次和 session 进度。
- 中部展示单词、配图和当前阶段允许查看的释义。
- 下部展示短语或例句、音频播放状态和下一步按钮。
- 音频未完成时下一步禁用。
- 最后一步提供认识、模糊、不认识。

### 7.3 生词本

顶部提供固定的“IELTS 英语｜TOPIK 韩语”分段切换栏，当前语言高亮。

语言切换规则：

- 列表、搜索、筛选和数量统计只作用于当前语言。
- 筛选类型包含全部、学习中、已掌握、我添加的。
- 切换语言时保留筛选类型，但清空搜索关键词。
- 从学习首页进入时默认继承当前学习语言。
- 在生词本手动切换后记住该选择；下次直接打开时恢复上次查看语言。
- 生词本语言选择不影响学习首页语言和学习队列。

词条展示：单词、中文释义摘要、学习状态、当前复习轮次、下次复习日期、来源。已掌握单词显示“已完成 60 天复习”。

详情页展示完整分层释义、配图、短语、例句及音频。支持编辑内容；用户添加的词条可以删除，已掌握词条可以重新加入复习。

空状态：

- 当前语言没有生词：显示添加第一个英语或韩语生词。
- 搜索无结果：显示当前语言中未找到该单词，并提供清空搜索。
- 筛选无结果：不误报整个生词本为空。

### 7.4 添加生词

- 默认使用生词本当前语言；从其他入口添加时需明确选择语言。
- 输入单词后生成相应文字、配图与音频。
- 英语生成音标、英文释义、中文、短语、例句及翻译。
- 韩语额外生成韩文释义和罗马音。
- 保存前显示完整预览，所有文字可修改，配图可重新生成。
- 必填字段与音频校验通过后才可保存并进入新词队列。
- 保存后返回原语言、原筛选位置。

### 7.5 我的

- 分别设置英语、韩语每日新词目标，默认各 30。
- 分语言查看学习中、已掌握和累计学习数量。
- 管理图片与音频缓存。
- 不提供排行榜、社交分享和发音评分。

## 8. 数据模型

### 8.1 Word

- `id`：稳定唯一标识。
- `language`：`en` 或 `ko`。
- `text`：单词原文。
- `normalizedText`：用于查重的规范化文本。
- `pronunciation`：英语音标或韩语罗马音。
- `definitionEn`：英文释义。
- `definitionKo`：韩语单词的韩文释义，英语词条为空。
- `definitionZh`：中文释义。
- `imageUrl`：配图地址或本地缓存路径。
- `phrase`：短语文本、中文翻译和音频地址。
- `example`：例句文本、中文翻译和音频地址。
- `wordAudioUrl`：单词音频地址或本地缓存路径。
- `source`：内置或用户添加。
- `contentStatus`：生成中、待完善、可学习。

### 8.2 StudyState

- `wordId` 与 `language`。
- 当前复习阶段。
- 上次完成日期和下次到期日期。
- 学习中或已掌握状态。
- 掌握反馈历史。

### 8.3 DailyProgress

- 日期与语言。
- 当日新词目标。
- 新词完成数与复习完成数。
- 当日已完成单词 ID，防止重复计数。

### 8.4 SessionProgress

- 日期、语言与任务单词 ID 顺序。
- 当前单词位置与当前学习步骤。
- 已完成音频步骤。
- 新词或复习类型。

SessionProgress 只用于恢复界面。跨天时作废当前 session 并重新生成队列；学习状态和每日统计以已提交的单词结果为准。

## 9. 生词查重与内容校验

- 英文去除首尾空格、合并连续空格并忽略大小写。
- 韩文使用规范化 Unicode 文本并去除首尾空格。
- 查重只在相同语言内进行。
- 重复添加时打开已有词条，不生成重复学习记录。
- 可学习词条必须包含当前语言要求的全部释义、短语、例句、配图和三段音频。
- 音频播放失败不能通过修改文字绕过音频门禁；内容修改后需要重新生成受影响文本对应的音频。

## 10. 异常处理

- 内容生成失败：保留输入和草稿，可重试或手动补全，不进入学习队列。
- 云端超时或限流：显示可理解的状态，不重复创建词条。
- 生成内容缺字段：标出具体缺失项，允许修改或重新生成。
- 音频失败或中断：不解锁，提供重试；恢复后从头播放。
- 图片加载失败：显示文字占位区域，可重试图片，不阻塞释义和音频学习。
- 离线：已有完整缓存的单词可继续学习；缺音频的单词暂缓，已有本地记录不受影响。
- 中途退出：恢复到当前步骤，当前音频重新播放。
- 跨天：历史统计不回写，新队列优先纳入逾期复习。
- 删除用户词条：二次确认后删除该词条及其学习状态，不影响其他数据。
- 云服务异常：只暂停新生成和未缓存资源获取，不破坏内置词库和本地学习记录。

## 11. 验收与验证重点

### 11.1 调度

- 英语和韩语每天分别最多分配设定数量的新词，默认 30。
- 复习优先于新词，逾期复习按到期日排列。
- D1、D2、D4、D7、D15、D30、D60 日期计算正确。
- 认识、模糊、不认识分别推进、重复和重置阶段。
- 完成 D60 后进入已掌握，手动重新加入后恢复调度。

### 11.2 学习流程

- 英语和韩语释义揭示顺序正确。
- 学习 session 中不会出现另一种语言。
- 单词、短语、例句音频未正常结束时不能继续。
- 重播、中断、后台切换和退出恢复均不会绕过音频门禁。
- 每个单词只计数一次，退出继续不会重复增加进度。

### 11.3 生词本

- 切换语言后列表、统计、搜索和添加语言正确。
- 搜索在切换语言时清空，筛选类型保留。
- 生词本切换语言不改变学习首页语言。
- 重复生词不会生成新记录。
- 内容缺失时无法进入学习队列。

### 11.4 异常与持久化

- 云端失败保留草稿，本地已有数据不丢失。
- 离线时只有完整缓存词条可完成学习。
- 图片失败不阻塞学习，音频失败必须阻塞。
- 删除词条有确认且只影响目标词条。

## 12. 首版范围边界

首版不包含账号体系、跨设备同步、跟读评分、排行榜、社交分享、付费系统和多用户管理。这些能力不作为当前实现的前置条件。
